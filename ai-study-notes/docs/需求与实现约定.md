# 拾页：需求与实现约定

## 已确认范围

- 面向课程听课、教材学习，教材和课件继续由用户提供给 AI；首版不包含课堂录音。
- 授权账号或配置 API 后，在同一工作台直接聊天和整理笔记；宽屏并排显示，窄屏同页切换。
- 新增文字聊天、多轮上下文、流式回答、本机历史、停止与重试；支持选择回答文字或整段加入笔记。
- 左侧选区右键支持原文、AI 排版、AI 精简；右侧阅读预览支持右键文字颜色、局部和整篇 AI 重排，包含表格修复。
- AI 选区结果先对照预览，可编辑、取消，确认后写入；右侧替换按原文位置及版本校验，颜色和 AI 写入均可撤销。
- 颜色写入 Markdown 内联 HTML；复制大纲到幕布时去掉颜色标记，保留原文件中的颜色。AI 操作只发送选区，共用现有额度限制。
- 保留 ChatGPT、DeepSeek 网页采集作为可选入口，支持电脑鼠标选中文字和采集图片。
- 自动总结先进入待确认草稿；可以批量采纳、忽略、删除、撤销。手动明确加入的内容无需等待模型。
- 正式笔记为 Obsidian 仓库里的真实 Markdown 文件，图片为仓库内附件。
- 普通 Markdown 和大纲 Markdown 两种模式。大纲正文每个节点独占一行，以 `- ` 开头，每级两个空格。
- 用 AI 双向转换两种笔记，默认另存。转换以保留原信息为目标，不主动扩写知识。
- 文件链接、图片引用、来源、公式尽量保留。普通预览不能替代完整的 Obsidian 插件生态。
- 提供复制原始大纲文本到幕布的按钮；首版无需幕布 MCP 或超级会员。
- 优先现有 Plus/Pro 的官方账号授权；接入状态、限制和用量明确显示，不伪装已连接。
- 普通程序处理保存、去重、排版；模型只读新增对话与相关上下文。被忽略内容不会自动再次出现。
- 性能优先，AI 请求不阻塞手动整理。100ms 操作反馈、普通文字多数在 500ms 内可见是目标，不是未经实测的承诺。
- 源码、测试和文档放在独立项目目录；构建包与本地发布资料单独存放，并从 Git 仓库排除。
- 已扩展为独立 Mac 应用与 DMG，保留本地网页版、网页扩展与可选 Obsidian 插件。安装后的应用无需 VS Code、系统 Node、终端或源项目目录。

## 工程约定

- 网页版使用 Node.js 内置模块；桌面版自带 Electron 和生产网络依赖。大型构建依赖与中间文件保存在系统临时目录，避免同步进笔记库。
- 本地服务仅监听 127.0.0.1。界面会话和扩展连接鉴权，OpenAI 凭据不发送到浏览器。
- macOS 凭据优先存入系统钥匙串；其他系统使用项目 .data 内受保护的文件，并明确展示存储方式。
- 只有完成官方身份签名、state、nonce、权限校验后才启用套餐调用。
- 正式笔记每次写入都基于最新内容和版本；保留人工编辑，冲突时停止写入并提示刷新。
- 优先由 Obsidian 插件在原生编辑器内应用变更；未连接插件时支持明确标记的本地文件方式。
- 网页版新笔记默认在项目的“笔记”目录中；独立应用的新仓库默认使用「拾页笔记」。导入旧版保留原输出目录，目录均可设置。
- 网页版的 AI 内容、来源和记录保存在项目 .data；独立应用按仓库保存到系统应用数据目录的 .data，替换 .app 不清空记录。
- 自动整理需用户开启，只处理已绑定笔记的完整工作台问答或外部采集内容；先聊后建笔记时可手动收集先前对话。
- 聊天与整理共用服务、预算和次数限制；聊天按完整轮次控制上下文，省略时明确提示。自动整理不直接改写正式笔记。
- 原始问答保存在各自运行方式的数据目录，与 Obsidian 中的正式笔记分开。新对话不自动读取网页历史或整篇笔记。
- 桌面版支持先选择仓库、确认导入原项目；保留授权标识，拒绝重复导入覆盖。账号凭据不进入 DMG，新电脑自行授权。
- 当前提供手动替换更新。正式互联网分发需 Developer ID 签名与 Apple 公证，自动更新另行配置。
- 从 0.2.1 起只制作 Apple 芯片 arm64 版本，不再构建 Intel 版。
- 全屏时关闭必须先完成原生退出全屏，再隐藏；Dock 恢复原尺寸，重复关闭或动画中恢复不能留下空的全屏桌面或不可操作的微小窗口。
- 自动化测试使用隔离服务和合成内容；真实调用单独记录，注明服务、模型、结果和用量。
