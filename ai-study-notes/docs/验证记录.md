## GitHub 资料整理

发布命令按源码目录白名单准备文件，排除个人数据、笔记、凭据、测试输出、依赖和旧安装包；生成源码 ZIP 并核对 ZIP 文件列表，核对复制前后的 DMG SHA-256。每次整理的文件数量与摘要写入本地 `整理清单.json`。

源码的基本复现检查为 `npm run check`、`npm test` 和 `npm run build`。核心测试使用隔离服务与合成内容，不调用真实模型。原始调试记录、截图和历史私人环境记录位于忽略目录，不纳入公开源码。

2026-10-22 首次公开源码整理后，将源码 ZIP 解压到独立临时目录进行复现：**51 项测试通过、45 个脚本语法检查通过，扩展与 Obsidian 插件构建成功**。该次源码 ZIP 包含 74 个文件；逐文件摘要、中文文件名 UTF-8 标记、文档内部链接、Git 忽略规则、DMG 与原件的一致性均已核对。之后补充第三方来源与许可文件，当前数量以生成的 `整理清单.json` 为准。

第三方许可原文由锁定安装的 Electron、Undici、electron-builder 与测试用 Playwright 包复制，逐文件与原件核对摘要。现有应用没有显式附带 Electron 的许可文件，已纠正原文档中“随运行时包含”的笼统描述；发布资料新增独立许可 ZIP，源码增加后续构建的 Resources 复制规则。本轮未重建 DMG，也未重新执行原生窗口界面检查或真实模型调用。

## 运行方法与验证边界

```sh
npm run check
npm test
npm run build
```

桌面与原生窗口检查另需安装 Playwright、准备对应 `.app`，并配置 `SHIYE_PLAYWRIGHT` 和必要时的 `SHIYE_APP_BINARY`；先创建 `.artifacts` 目录。详见 [构建与发布](Mac应用构建与发布.md)。

当前验收环境是 Apple Silicon Mac，macOS 最低版本声明来自构建配置，不代表已逐一测试每个 macOS 版本。其他 Mac 首次下载时的系统提示、钥匙串权限、真实账号资格、长课程内容下的 AI 质量与延迟，需要对应环境确认。当前安装包未公证，没有在线自动更新。
