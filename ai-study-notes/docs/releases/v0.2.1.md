# 拾页 v0.2.1 · Apple Silicon 测试版

在同一个界面与 AI 对话、选取回答、审核总结，生成保存于 Obsidian 仓库的 Markdown 笔记。

## 本次修复

- 修复 Mac 全屏后点击关闭留下空黑屏的问题。
- 从 Dock 恢复时还原正常窗口尺寸，处理异常微小窗口与全屏动画中的重复关闭、激活。
- 关闭再恢复保留未提交界面内容。
- 后续仅提供 Apple Silicon（arm64）安装包。

## 主要功能

支持 ChatGPT 账号授权与 DeepSeek / OpenAI API 连接、流式文字聊天、选中文字右键加入笔记、AI 排版与精简、待确认总结草稿、笔记着色与 AI 重排、普通 Markdown / 大纲模式双向转换、复制大纲到幕布。可选网页扩展和 Obsidian 原生插件。

可用模型与权限以实际账号授权和服务返回结果为准，应用不附带账号、密钥或共享额度。当前不提供对话图片上传、图像语义分析或在线自动更新。

## 下载与安装

下载 `Shiye-0.2.1-mac-arm64.dmg`，适用于 **M 系列芯片的 Mac，macOS 13 或以上**。打开后把「拾页」拖入 Applications，再选择自己的笔记仓库。无需安装 Node.js、VS Code 或保留源码。

当前为临时签名（ad-hoc）的测试版，**尚未经 Apple Developer ID 签名与 Apple 公证**。下载后若系统拦截，请先确认来源，再参照 [Apple 首次打开说明](https://support.apple.com/zh-cn/102445) 操作。

已有版本：先退出应用，再替换「应用程序」里的旧版。笔记仍在所选仓库，聊天和偏好位于 `~/Library/Application Support/拾页/`，凭据在钥匙串；替换 `.app` 不主动清除这些数据。新电脑需要自行授权或填写 API Key。

附件 `SHA256SUMS.txt` 提供 DMG 完整性校验，`安装说明.txt` 提供操作说明。本次整理沿用已验证的 0.2.1 安装包，未因公开文档和发布工具变更重新打包。安装包不含个人笔记、聊天记录、账号或密钥。
