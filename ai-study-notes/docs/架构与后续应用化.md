# 架构与后续应用化

## 为什么选择这三个部分

浏览器扩展最容易读取用户在现有网页中选中的内容，并保留 ChatGPT、DeepSeek 的登录和网站体验。原生侧栏由浏览器管理，不依赖把第三方网站塞进 iframe。

本地服务负责真实文件、结构化草稿、账号授权、token 预算和版本冲突。网页版运行时使用 Node.js 内置模块；桌面版使用内置 Electron 与 Undici 网络适配，大型构建依赖保存在系统临时目录。页面采用原生模块和 DOM，所有显示的来源内容按文本处理，不执行聊天中的 HTML 或脚本。

Obsidian 插件负责访问正在编辑的笔记和原生草稿栏。它是可选适配层，不承担模型调用，也不持有模型 access token。扩展与插件仅持有本机连接码；模型凭据由本地服务保存在系统钥匙串。

## 数据如何流动

工作台内聊天为默认入口：本机服务使用已授权 ChatGPT 的 Responses 接口，或 DeepSeek 的 Chat Completions 接口，流式返回回答。ChatGPT 套餐预览按要求使用 `store:false`、`stream:true`，显式传递预算内最近的完整问答，不依赖服务端会话 ID。DeepSeek 同样流式读取，默认关闭深度思考以控制延迟。

问答先持久记录在 `.data/state.json` 的 chats 中。生成时只在内存累积文字，通过事件流推送；开始和结束时落盘，避免逐 token 写入 iCloud。刷新可读取进行中的完整片段；进程重启后未完成回答标为中断，可重试。成功回答才转为对应笔记的整理来源，停止和失败的部分回答仅保留在聊天中，仍可由用户明确摘录。

每轮绑定发送时选择的笔记，完整来源包含对话与消息 ID。聊天不会把整篇笔记隐式发送给模型。对话、整理共享预算和频率限制，单次提交编号去重；一个聊天回答和一个整理任务可并行，文件写入仍由串行事务与版本检查保护。

外部网页采集继续使用以下流程：

1. 选中网页文字，或点击图片采集。
2. 扩展携带本机连接码，将内容发到 127.0.0.1。
3. 明确的手动摘录直接追加，图片落为真实文件；普通对话采集先记为来源。
4. 整理只向模型发送未处理的消息、相关笔记片段、有限的排除提示。
5. 模型返回结构化内容块和来源 ID，校验完成后进入草稿。
6. 用户采纳后，由对应模式的序列化器生成 Markdown。
7. 原生连接时通过 Obsidian 编辑器或 Vault.process 写入；本地模式使用版本校验与临时文件替换。

图片下载和文件保存不需要向模型传图。首版不提供图像语义理解。字体、样式、图标均随本地项目提供，界面不依赖在线 CDN。

## 文件和修改保护

每次采纳均先读取当前版本，基于 SHA-256 检测变化。用户手动保存前，界面阻止切换或新建笔记。外部版本变化时拒绝覆盖，让用户刷新后再处理。原生插件连接中断时不自动回退到可能过时的磁盘版本。

历史最多保留 15 次程序写入。撤销只在文件仍等于本次写入结果时允许，不能越过外部修改强行回滚。它是近期操作恢复机制，不能替代文件备份或同步版本历史。

忽略草稿和主动删除已采纳内容会影响下一次整理的排除提示。完全相同的内容还能通过本地指纹去重；模型用不同措辞重述同一概念时，仍需用户判断。

## 响应速度

侧栏到本机服务的文件操作没有模型延迟。AI 任务异步进行，手动采集和笔记编辑继续可用。通知通过持久事件流更新，避免高频轮询文件。Obsidian 打开笔记时使用最小局部编辑，避免重置整篇编辑器。

实际时间受网页大小、Obsidian 插件、磁盘同步和网络影响；没有承诺固定延迟。集成测试的文件读写和批量采纳在隔离本机环境中完成，但不能直接视为真实 Obsidian 运行性能。

## 独立 Mac 应用（已实现）

现有核心、账号授权和文件存储不依赖工作台的打开方式。已增加 Electron 桌面窗口、Mac 菜单、仓库选择、旧版数据导入、应用生命周期和 DMG 打包，自带运行环境，不依赖系统 Node 或源项目目录。源码沿用原有界面与核心；浏览器扩展仍负责原有网站采集。

`.app` 内只保存程序。笔记继续保留在所选仓库，应用记录改为 `~/Library/Application Support/拾页/` 下按仓库分别保存，凭据继续使用钥匙串。导入保留原连接标识，不移动笔记，不覆盖旧项目。桌面版使用内置 Node 24 和 Undici 代理适配，网页版继续使用原有 Node 网络设置。

安装包在 `release/`；从 0.2.1 起仅制作 Apple Silicon 版，发布整理不包含旧版 Intel 包。当前只有临时签名，没有 Apple 公证和在线自动更新。全屏关闭通过窗口生命周期管理等待原生退出动画结束，再恢复尺寸并隐藏。构建、安装、备份与正式发布流程见 [Mac应用构建与发布](Mac应用构建与发布.md)。

独立窗口使用现有的接口聊天和笔记界面。若改为内嵌整个 ChatGPT / DeepSeek 网站，仍需要另行处理网站登录、弹窗、下载、上传和页面适配；当前版本不内嵌第三方网站。浏览器扩展继续负责网站历史和网页专属内容采集。
