# 拾页 · AI 学习笔记

在同一个界面与 AI 对话、摘录回答、审核总结，把自己决定留下的内容保存为 Obsidian 笔记。面向课程和教材学习，支持普通 Markdown 与可复制到幕布的大纲。

提供独立 Mac 应用，也保留本地网页版、网页采集扩展和可选 Obsidian 插件。当前版本 **0.2.1**，支持 **Apple Silicon（M 系列芯片），macOS 13 或以上**。

## 安装 Mac 应用

1. 到本仓库的 **Releases（发行版）** 下载 `Shiye-0.2.1-mac-arm64.dmg`。
2. 打开 DMG，将「拾页」拖入 Applications（应用程序），再打开应用。日常使用无需 VS Code、Node.js、终端或项目源码。
3. 选择自己的 Obsidian 仓库或普通笔记文件夹，新仓库默认将笔记放入「拾页笔记」子目录。
4. 在「连接与偏好」中授权 ChatGPT，或填写 DeepSeek / OpenAI API Key；读取模型、选择并保存后，即可在左侧聊天。

当前安装包采用临时签名（ad-hoc），**尚未经 Apple Developer ID 签名与 Apple 公证**。通过网络下载后，macOS 可能拦截首次打开；确认来源后，按 [Apple 的首次打开说明](https://support.apple.com/zh-cn/102445) 操作。当前没有在线自动更新，更新时先退出应用，再替换「应用程序」里的旧版。

已有本地网页版记录时，先退出旧版，再在首次设置中选择原笔记仓库，导入旧 `ai-study-notes` 项目。导入复制聊天、草稿、偏好和连接标识，原数据与原笔记保留；导入后使用应用版继续学习。**若旧笔记在项目的 `笔记/` 内，请保留这个目录，不要随源码一起删除。**

## 怎样使用

先新建一篇普通笔记或大纲笔记，再开始聊天。宽窗口左侧为对话、右侧为笔记；窄窗口可切换「AI 对话 / 笔记与草稿」。

- **手动摘录**：选中 AI 回答后右键，选择「原文加入笔记」；也可使用浮动按钮或「整段加入笔记」。保存原文不调用模型。
- **AI 整理选区**：右键选择「AI 排版后加入」或「AI 精简后加入」。先核对原文和结果，可编辑、取消，确认后才写入。
- **自动草稿**：选好目标笔记后开启「自动整理」，完整问答会生成待确认草稿，可逐条或批量采纳、忽略。也可手动点击「整理新增对话」。默认关闭，不直接改写正式笔记。
- **编辑笔记**：右侧可编辑 Markdown 源文；阅读预览中选中文字后右键可着色、让 AI 重排段落或表格，也可整篇重排。写入有版本检查，并支持撤销最近操作。
- **两种模式**：普通 Markdown 使用标题、段落和表格；大纲每个节点独占一行，以 `- ` 开头，每级缩进两个空格。点击「AI 转换 ⇄」生成另一模式的新文件，保留原文件。
- **复制到幕布**：在大纲模式点击「复制到幕布」，再粘贴到幕布转换思维导图。无需连接幕布账号；复制会移除颜色标记。本地图片和 Obsidian 双链不会自动上传或同步到幕布。

聊天支持流式回答、多轮上下文、本机历史、停止和重试。先聊天后建笔记时，可点击「将本对话用于整理」。发送时选择的「本轮整理到」决定该轮问答所属的笔记。账号授权不会导入 ChatGPT 网页历史。

当前工作台内聊天支持文字输入。图片可通过「加入学习片段」或网页扩展保存为笔记附件，暂不提供对话图片上传、图像语义分析、网页搜索或第三方网站原生工具。

## 连接 AI 与控制用量

ChatGPT 账号授权、OpenAI API 和 DeepSeek API 是不同连接方式。ChatGPT 可用权限、模型及额度以实际授权结果和模型列表为准；安装包不附带账号、API Key 或共享额度。

聊天、生成草稿、AI 排版/精简、AI 重排和模式转换会调用模型。手动摘录、保存、着色、去重和浏览笔记不调用模型。开启自动整理后，一次回答可能另触发一次整理请求。

程序按上下文预算选择最近完整问答；整理只发送未处理来源与相关片段，选区操作只发送所选内容。设置可限制上下文、每日 token 预算和每小时调用次数。早期上下文被省略时会提示，本机历史仍保留；用量优先使用服务返回值，无法取得时标注估算。预算是本机控制，不能代替服务商的账单或套餐统计。

联网失败时，在「连接与偏好 → 后台联网方式」检查连接，可跟随系统代理或填写自己的 HTTP/Mixed 代理地址。端口以自己的代理软件配置为准。此设置只影响拾页，不修改系统代理或 VPN。失败请求不会自动无限重试。

## Obsidian 与网页扩展

默认直接读写所选仓库内的真实 `.md` 文件，无需安装插件。拾页预览支持常用 Markdown、表格、图片和双链入口；完整双链解析、反向链接、公式和插件效果请在 Obsidian 中查看。

需要 Obsidian 原生编辑接入时，在 Mac 应用的「连接与偏好 → 浏览器与 Obsidian」安装可选插件，再到 Obsidian 的第三方插件页面启用，并填入本机连接码。插件可读取正在编辑的内容并局部写入；连接中断时停止写入，避免覆盖人工编辑。

如需继续使用原有 ChatGPT / DeepSeek 网页，在 Chrome 或 Edge 加载扩展，打开网页后点击扩展图标，即可在网页旁显示笔记侧栏。扩展支持选字摘录、图片采集、采集当前对话和持续采集；持续采集与自动整理是独立开关，默认均关闭。只采集浏览器已加载的消息，网站改版可能需要更新适配器。支持 `chatgpt.com` 和 `chat.deepseek.com`，暂不采集独立客户端。

源码使用者先运行 `npm run build`，再在浏览器扩展管理页开启开发者模式，加载 `dist/extension`。填入工作台提供的本机地址和连接码，刷新已经打开的 AI 标签页。应用版也提供扩展下载入口。

## 数据保存与窗口操作

| 内容 | Mac 应用保存位置 |
| --- | --- |
| 正式笔记和图片 | 所选笔记仓库，新仓库默认在「拾页笔记」内 |
| 聊天、草稿、偏好、用量及连接信息 | `~/Library/Application Support/拾页/`，按仓库隔离 |
| 账号和 API 凭据 | macOS 钥匙串 |
| 程序 | `/Applications/拾页.app`，与个人数据分开 |

红色关闭按钮隐藏窗口；全屏时先完成退出全屏，再隐藏。点击 Dock 图标恢复正常窗口。`Command+Q` 完全退出并停止后台服务，`Command+S` 保存，`Command+,` 打开偏好设置。通过「文件 → 笔记仓库与数据」切换仓库。

备份时先退出应用，再备份笔记仓库和应用数据目录。笔记可沿用自己的同步方式；不要让多台设备同时写入同一个程序状态文件。**不要公开应用数据、连接码、账号凭据和私人学习资料。**本地保存不等于离线推理：执行 AI 操作时，所需内容会发送至所选服务。

## 从源码运行

本地网页版需要 Node.js 22+，不需安装第三方运行依赖；网页版的显式后台代理功能需要 Node.js 25.4+。克隆或解压后，在项目根目录运行：

```sh
npm run check
npm test
npm run build
SHIYE_VAULT="/你的笔记仓库绝对路径" npm start
```

打开 `http://127.0.0.1:17861`。首次使用请在设置里确认输出目录（相对 `SHIYE_VAULT`），默认 `ai-study-notes/笔记`。网页版的聊天与偏好保存在项目 `.data/` 中。Mac 上凭据仍使用钥匙串。

双击 `启动拾页.command` 会把项目父目录作为默认笔记仓库；只有项目确实放在仓库内时才使用这个默认值。安装可选 Obsidian 插件时，也应明确目标仓库：

```sh
node scripts/install-obsidian.mjs "/你的笔记仓库绝对路径"
```

Mac 应用开发和打包需要 macOS、Node.js 22.19+、npm、Xcode Command Line Tools。构建脚本按锁文件安装 Electron 等依赖到系统临时目录，源码目录无需先运行 `npm install`。

```sh
npm run desktop
npm run build:mac
npm run prepare:github
```

仅构建 arm64。DMG 与应用 ZIP 输出到 `release/`，GitHub 发布资料输出到 `github-publish/v<版本>/`，两者均被 Git 忽略。整理命令另需 Python 3（仅使用标准库生成保留中文文件名的源码 ZIP）和已构建的同版本 DMG，重复运行会替换该版本自动生成的发布资料。
